# References

Format conventions and measurements reflect industry-standard practice. This
package contains original documentation and original code.

## Source types used for factual grounding

- **Industry-standard page geometry and element positions** — as taught in
  screenwriting education generally (font, margins, column positions, lines
  per page). These are widely-published facts/conventions, not the
  copyrighted expression of any single guide; no passages were copied from
  any book, article, or website.
- **The Fountain specification** — an open, freely implementable plain-text
  screenwriting markup created in 2012 by John August and Stu Maschwitz.
  Used here as the canonical human-readable interchange syntax.
- **Final Draft XML (`.fdx`)** — referenced only as a factual target export
  format (an XML schema for scene/element data), documented from its
  observed structure. No converter code from any third-party application
  was used, read, or translated.
- **General industry practice for duration/runtime ratios and script
  length norms** — the "one page ≈ one minute" convention and typical
  feature-length ranges, as widely reported facts, not as copied prose.
